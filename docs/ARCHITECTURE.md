# Архитектура Web Performance Analyzer

## Структура приложения (этап 01)

```text
Браузер пользователя
        |
        v
React + Vite (http://localhost:5173)
        |
        | GET /api/health
        | Vite проксирует /api на localhost:3001
        v
Fastify (http://127.0.0.1:3001)
        |
        v
JSON { "status": "ok", ... }
```

Frontend отвечает за отображение информации и действия пользователя. Backend отвечает за API и серверную обработку.

## Реализовано в части 1

- `GET /api/health` — проверка работоспособности сервера.
- React получает результат настоящего HTTP-запроса и показывает состояние подключения.
- Модульный запуск Fastify (`buildApp`) позволяет тестировать API без отдельного сервера.

## Планируемые компоненты

1. Модуль проверки URL перед анализом (учесть SSRF, запрет внутренних адресов, редиректы и тайм-ауты).
2. Сервис запуска Chrome и Lighthouse.
3. Извлечение метрик из JSON-аудита.
4. Алгоритм правил и приоритетов рекомендаций.
5. PostgreSQL / Prisma и история анализов.
6. Интерфейс результатов и сравнения проверок.

## Примечание

В части 1 никакие сайты ещё не анализируются. Данные `/api/health` — статус приложения, **не имитация отчёта Lighthouse**.
