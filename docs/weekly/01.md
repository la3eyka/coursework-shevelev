## Как проверить выполнение

1. `cd backend; npm install; npm run test; npm run build; npm run dev`.
2. В другом окне PowerShell: `cd frontend; npm install; npm run build; npm run dev`.
3. Открыть `http://localhost:5173` и проверить «Сервер подключён».
4. Перейти на `http://127.0.0.1:3001/api/health` и увидеть JSON со `status: ok`.
